# Рядом — видеозвонки с друзьями

Статический сайт: без своего сервера, без регистрации, без подписок.
Голос и видео идут напрямую между участниками (WebRTC), сигнальный сервер — бесплатный PeerJS cloud.

## Публикация на GitHub Pages (бесплатно)

1. Создайте репозиторий на GitHub и загрузите в него все файлы этой папки (вместе с `vendor/`).
2. В репозитории: **Settings → Pages → Build and deployment → Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

Камера и микрофон работают только по HTTPS — GitHub Pages его даёт.

## Что где

| Файл | Что внутри |
|---|---|
| `js/config.js` | Сигнальный сервер и список STUN/TURN — всё, что может понадобиться заменить |
| `js/app.js` | Комнаты, пароль, звонки «каждый с каждым», звук, раскладки, запись, снимки |
| `js/schedule.js` | Запланированные встречи: окно создания, часовые пояса, отсчёты |
| `js/effects.js` | Всплывающие реакции и конфетти |
| `js/games.js` | Игровая комната: Сулифа (камень, ножницы, бумага) |
| `js/cinema.js` | Кино вместе: общий плеер внутри звонка, субтитры, связь с расширением «Сеанс» |
| `css/style.css` | Оформление; цвета, радиусы, отступы, тени — переменные в начале файла |
| `fonts/` | Шрифт Onest (заголовки), хранится в проекте — без сторонних сервисов |

PeerJS 1.5.5 подключается с jsDelivr с проверкой целостности (SRI).
Если поменяете сигнальный сервер в `config.js`, добавьте его адрес в `connect-src` в meta-теге Content-Security-Policy в `index.html`.

## Запланированные встречи

Кнопка «Запланировать» на главной: название, дата, время, длительность и часовой пояс (по умолчанию — ваш).
Своего сервера нет, поэтому всё о встрече хранится в самой ссылке, после `#` — эта часть адреса на сервер не отправляется.
Войти можно заранее. В назначенное время окончания звонок завершается для всех, и по ссылке больше не пускает.
Если у встречи есть пароль, в ссылке лежит только соль и проверочная метка, сам пароль сообщите участникам отдельно.

## Кино вместе

Кнопка «Развлечения» → «Кино вместе» открывает кинозал сразу у всех, звонок при этом не прерывается: лица уезжают полоской наверх. Кто зайдёт позже, попадёт сразу в кинозал на нужную секунду.

- Фильм — прямая ссылка (`https://…mp4`, `webm`, `m3u8`) или свой файл. Файл никуда не загружается: у каждого должен быть свой, время общее.
- Каждый загружает видео сам; по сети идут только «плей», «пауза» и время. Общее состояние хранит hub комнаты, поэтому кинозал переживает уход любого участника.
- Качество, озвучка и субтитры у каждого свои. Субтитры — из ссылки, из потока или свой файл (.srt, .vtt, .ass; можно перетащить на экран).
- Звук фильма проигрывается через WebRTC-петлю, чтобы эхоподавление браузера вычитало его из микрофона (файлы, HLS и ссылки с CORS). Когда кто-то говорит, фильм приглушается.
- Расширение «Сеанс» (с версии 1.2.0) работает и здесь: достаёт ссылку с сайта с фильмом, подставляет её в кинозал и пропускает видео, которое сайт отдаёт только «своим».
- Клавиши: пробел — пауза, ← → — 10 секунд, F — весь экран, C — субтитры.
